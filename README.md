# Malovaný les

3D edukační hra pro prvňáčka. Vendulka chodí lesem malovaným tahy štětce, plní úkoly a zapisuje objevy do deníku.

- Čtyři roční období, která se odemykají postupně: podzim, zima, jaro, léto.
- Osm úkolů: fyzika (plave/potopí se, páka), příroda (kdo co jí, semínko), počítání do 10, čtení a doplňování písmen.
- K dalšímu úkolu vede králíček Zajdík: jednou běží napřed a volá „POBĚŽ ZA MNOU!“, jindy Zajdíci sedí podél cesty jako fáborky.
- Texty velkými tiskacími písmeny, bez hlasu.
- Ovládání: kliknutí nebo ťuknutí na zem, tažením se otáčí pohled; WASD nebo šipky, Shift běh, mezerník skok, kolečko přiblížení.

## Spuštění

Otevři `index.html` v prohlížeči, nebo hru nasaď jako statický web (GitHub Pages z větve `main`, kořen repozitáře).
Adresa s `#vse` na konci odemkne všechna období najednou.

Postup se ukládá do prohlížeče na daném zařízení.
